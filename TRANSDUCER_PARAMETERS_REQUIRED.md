# Необходимые параметры трансдьюсера для оптимизации выходного каскада

## Текущее состояние в SonarCore

**Реализовано:**
- Базовая модель: `core/transducer_model.py`
- Простые параметры: `f_min`, `f_max`, `S_TX`, `S_RX`, `Z` (константа)
- Упрощенная модель TVR (константа или линейное затухание вне полосы)

**Недостает для оптимизации выходного каскада:**
- BVD модель импеданса (частотно-зависимый импеданс)
- Табличная или параметрическая TVR(f)
- Модель нелинейности
- Ограничения по мощности и напряжению

---

## Критически необходимые параметры

### 1. BVD параметры (Butterworth-Van Dyke модель)

**Для расчета частотно-зависимого импеданса:**

```json
{
  "bvd": {
    "R_s": 50.0,        // Последовательное сопротивление [Ом]
                       // Механические потери, определяет Q-фактор
    "L_s": 0.0025,     // Последовательная индуктивность [Гн]
                       // Эффективная масса пьезоэлемента
    "C_s": 1.35e-8,    // Последовательная емкость [Ф]
                       // Упругость пьезоэлемента
    "C_p": 2.7e-9      // Параллельная емкость [Ф]
                       // Зажимная емкость (clamped capacitance)
  }
}
```

**Зачем нужно:**
- Расчет импеданса на каждой частоте: `Z(f) = f(R_s, L_s, C_s, C_p, f)`
- Компенсация огибающей: `G_Z(f) = sqrt(|Z(f)| / |Z_ref|)`
- Расчет мощности: `P_elec(t) = |V_piezo(t)|² / Re(Z(f(t)))`
- Оптимизация согласования с трансформатором и индуктивностью

**Формула импеданса:**
```
Z(ω) = 1 / (jωC_p + 1/(R_s + jωL_s + 1/(jωC_s)))
```

**Резонансные частоты (вычисляются или задаются):**
```json
{
  "resonance": {
    "f_s": 30000,      // Последовательный резонанс [Гц]
                       // Минимум |Z|, f_s = 1/(2π√(L_s·C_s))
    "f_p": 32000       // Параллельный резонанс [Гц]
                       // Максимум |Z|, f_p = f_s·√(1 + C_s/C_p)
  }
}
```

### 2. TVR (Transmitting Voltage Response) - частотная характеристика

**Текущая проблема:** Используется константа `S_TX` или упрощенная модель

**Требуется:** Табличная или параметрическая зависимость TVR(f)

**Вариант A: Табличная (рекомендуется для точности)**

```json
{
  "tvr": {
    "type": "tabulated",
    "frequencies": [10000, 15000, 20000, 25000, 30000, 35000, 40000, 45000, 50000],
    "values": [142, 144, 146, 147, 148, 147, 146, 144, 142]
    // [дБ re 1μPa/V @ 1m]
  }
}
```

**Вариант B: Параметрическая модель**

```json
{
  "tvr": {
    "type": "model",
    "f_center": 100000,       // Центральная частота [Гц]
    "TVR_center": 148,         // TVR на центральной частоте [дБ]
    "bandwidth_3db": 190000,  // Полоса -3 дБ [Гц]
    "shape": "gaussian"      // или "butterworth", "chebyshev"
  }
}
```

**Зачем нужно:**
- Компенсация огибающей: `G_TVR(f) = TVR(f_ref) / TVR(f)`
- Точный расчет Source Level: `SL = TVR(f) + 20·log₁₀(V)`
- Учет реальной АЧХ трансдьюсера при оптимизации

---

### 3. Модель нелинейности

**Для учета THD и ограничения рабочего диапазона:**

```json
{
  "nonlinearity": {
    "type": "polynomial",  // или "duffing", "volterra"
    "coefficients": {
      "a1": 1.0,           // Линейный коэффициент
      "a2": 0.0,           // Квадратичный (обычно 0)
      "a3": 0.05,          // Кубический (нелинейность)
      "a5": 0.001          // 5-й порядок (опционально)
    },
    "V_linear_max": 150    // Порог линейности [В]
                           // При V > V_linear_max: THD > THD_max
  }
}
```

**Альтернатива: Модель Дуффинга**

```json
{
  "nonlinearity": {
    "type": "duffing",
    "m": 0.01,             // Эффективная масса [кг]
    "c": 0.1,              // Демпфирование [Н·с/м]
    "k1": 1e6,             // Линейная жесткость [Н/м]
    "k3": 1e9              // Кубическая жесткость [Н/м³]
  }
}
```

**Зачем нужно:**
- Расчет THD: `THD(V) = f(a3, a5, V)`
- Ограничение рабочего диапазона: `V_piezo(t) ≤ V_linear_max`
- Компенсация нелинейности: `w_NL(f) = 1 / (1 + k·THD(V(f)))`
- Оптимизация предыскажения (DPD)

---

### 4. Ограничения по мощности и напряжению

**Для проверки ограничений при оптимизации:**

```json
{
  "limits": {
    "P_elec_max": 500,      // Максимальная электрическая мощность [Вт]
                            // Пиковая мощность
    "P_elec_avg_max": 200,  // Максимальная средняя мощность [Вт]
    "V_max": 200,           // Максимальное напряжение [В]
                            // Пиковое напряжение на пьезо
    "V_linear_max": 150,    // Порог линейности [В]
                            // Максимальное напряжение без значительного THD
    "I_max": 10             // Максимальный ток [А]
  }
}
```

**Зачем нужно:**
- Проверка ограничений: `P_elec(t) ≤ P_elec_max`
- Проверка линейности: `V_piezo(t) ≤ V_linear_max`
- Оптимизация в допустимых пределах

---

### 5. Дополнительные параметры для точности

**Акустическая мощность:**

```json
{
  "acoustic": {
    "P_acoustic_max": 100,  // Максимальная акустическая мощность [Вт]
    "efficiency": 0.3        // Эффективность преобразования (электрическая → акустическая)
                             // Обычно 20-40% для пьезоэлектрических трансдьюсеров
  }
}
```

**Температурная зависимость (опционально):**

```json
{
  "temperature": {
    "T_ref": 20,            // Опорная температура [°C]
    "TC_f_s": -0.001,       // Температурный коэффициент f_s [1/°C]
    "TC_TVR": -0.0005       // Температурный коэффициент TVR [1/°C]
  }
}
```

## Приоритет реализации

**Критический (для базовой оптимизации):**
1. ✅ BVD параметры (R_s, L_s, C_s, C_p)
2. ✅ Метод `get_impedance(f)` 
3. ✅ Табличная TVR(f)
4. ✅ Метод `get_tvr(f)` с интерполяцией
5. ✅ Ограничения (V_max, P_elec_max)

**Важный (для точной оптимизации):**
6. ✅ Модель нелинейности
7. ✅ Метод `get_thd(V)`
8. ✅ Резонансные частоты (f_s, f_p)

**Опциональный (для расширенной оптимизации):**
9. ⚠️ Температурная зависимость
10. ⚠️ Акустическая эффективность

## Источники данных

**Где взять параметры:**

1. **BVD параметры:**
   - Измерить импеданс на разных частотах (импеданс-анализатор)
   - Подобрать R_s, L_s, C_s, C_p для наилучшего соответствия
   - Или взять из datasheet производителя (если указаны)

2. **TVR(f):**
   - Из datasheet (обычно есть график или таблица)
   - Измерить калибровкой (гидрофон на расстоянии 1м)
   - Аппроксимировать по известным точкам

3. **Нелинейность:**
   - Измерить THD на разных уровнях напряжения
   - Подобрать коэффициенты a3, a5
   - Или использовать типичные значения для пьезоэлектриков

4. **Ограничения:**
   - Из datasheet (максимальные значения)
   - Из опыта эксплуатации
   - Из расчетов тепловых режимов

## Связь с оптимизацией выходного каскада

**Использование параметров в оптимизации:**

1. **Расчет импеданса Z(f)** → компенсация огибающей G_Z(f)
2. **Расчет TVR(f)** → компенсация огибающей G_TVR(f)
3. **Расчет мощности P_elec(t)** → проверка ограничений
4. **Расчет THD(V)** → ограничение рабочего диапазона
5. **Оптимизация V_dd, n, L** → максимизация битрейта при соблюдении ограничений

**Без этих параметров невозможно:**
- ❌ Рассчитать частотно-зависимый импеданс
- ❌ Сформировать компенсирующую огибающую A(t)
- ❌ Оптимизировать согласование (трансформатор + индуктивность)
- ❌ Учесть нелинейность при высоких уровнях
- ❌ Проверить ограничения по мощности и напряжению
